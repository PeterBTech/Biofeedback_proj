# Biofeedback project

This project's aim is to make an ml model, train it on EEG data, and have it accurately predict the state associated with the data.

**Work in progress** Building in phases.

**Currently in:** Part 1 - have brain wave measurements continuously arrive into the program

## Stack
Python 3.10+ · BrainFlow · NumPy · SciPy · MNE · scikit-learn · Pygame
